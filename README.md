# IMx

IMx is a local multi-agent desktop cockpit for orchestrating Codex agents in parallel.

This repository is the foundation for the IMx MVP: a blue, terminal-first Agentic Development Environment with a **PILOTO** orchestrator, multiple local terminal panes, configurable squads, manual agent mode, live logs, and isolated Git worktrees when possible.

> Status: MVP implementation is being developed on the `feat/imx-mvp` branch.
